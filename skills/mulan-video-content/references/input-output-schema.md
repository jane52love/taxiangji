# 输入输出框架

这个框架用于整理思路，不是让木兰一次性填写完整表格。能从素材中判断的，就先判断；真正影响文案但缺失的信息，再向木兰确认。

## 输入素材清单

```yaml
项目:
  主题:
  一句话核心观点:
  平台: 视频号 | 抖音 | 小红书 | 朋友圈 | 其他
  目标口播时长_秒:
  目标受众:
  发布目标: 记录生活 | 文化传播 | 本地宣传 | 带出产品或地点 | 引发讨论 | 其他

媒体素材:
  文件:
  可见场景:
  人物:
  物件:
  动作:
  口播或字幕:
  可用关键帧:
  缺失画面:

知识库:
  文件:
  可使用事实:
  地方词:
  人物故事:
  时间或季节:
  不确定信息:

木兰想法:
  原始笔记:
  想讲的角度:
  必须包含:
  必须避免:
  个人记忆或看法:

对标内容:
  账号或视频:
  为什么参考:
  可借鉴结构:
  可借鉴标题方式:
  不能照抄的部分:

木兰过往内容:
  样本:
  常见主题:
  口吻规则:
  好用句子:
  不想继续使用的写法:
```

## 需要确认的维度

这些维度会影响最终文案，缺失时要向木兰确认：

- 主题：这条视频一句话到底讲什么
- 场景类型：文化习俗、地方特产、身边故事、生活场景、文化宣传，或混合类型
- 平台：视频号、抖音、小红书、朋友圈或其他
- 时长：30 秒、60 秒、90 秒、2-3 分钟或自定义
- 叙述身份：木兰是见证者、参与者、采访者、讲解者，还是推荐者
- 情绪方向：好奇、怀念、自豪、好笑、感动、发问、实用
- 受众：本地人、外地人、相似处境的乡村女性、游客、潜在购买者、家人朋友
- 事实严格度：哪些必须查知识库，哪些必须问当事人
- 隐私边界：真实姓名、露脸、家庭细节、收入、年龄、具体住址
- 转化目标：不转化、引导关注/评论、到访、购买、分享、联系
