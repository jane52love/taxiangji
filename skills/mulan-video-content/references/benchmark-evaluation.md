# 成稿评测标准

每次生成口播文案或视频脚本后，都按这个 benchmark 自检。它不是给用户看的打分表，而是用于改稿的内部标准。发现问题后直接改文案，不要只解释问题。

## 权重

- 完整度：20%
- 黄金 3 秒：40%
- 表达够深入：30%
- 结尾：10%

权重意味着改稿优先级：黄金 3 秒最重要，其次是表达深度，再是完整度和结尾。

## 1. 完整度，20%

检查前因后果是否讲清楚。

必须回答：

- 这件事是谁和谁之间发生的？
- 起因是什么？
- 中间发生了什么关键动作或对话？
- 木兰为什么被这件事打动？
- 观众听完能不能不追问背景，也基本听懂？

常见问题：

- 只写感受，没有交代发生了什么。
- 只写事实，没有说明为什么值得拍。
- 人物关系不清楚，例如“她”“他们”指代混乱。
- 时间顺序跳太快，观众跟不上。

改稿方法：

- 用 1-2 句补清楚人物关系和起因。
- 保留最关键的现场对话。
- 删除和主线无关的解释。
- 不为了完整而写成长背景介绍。

## 2. 黄金 3 秒，40%

开头 3 秒必须抓人。优先用真实画面、真实对话、反差或问题，不要用空泛铺垫。

优先开头方式：

- 现场对话开头：“她特别自豪地说，不是哦，是我家孙女买的。”
- 画面动作开头：“邻居奶奶手里提着一袋吃的，从我门口走过去。”
- 反差开头：“我以为是她儿子买的，没想到是还在上学的孙女。”
- 问题开头：“你有没有问过爷爷奶奶，最近想吃什么？”
- 悬念开头：“这一袋吃的，让奶奶高兴了很久。”

避免开头方式：

- “今天我想跟大家分享一个故事。”
- “亲情是中华民族的传统美德。”
- “在现代社会中，很多孩子……”
- “大家好，我是木兰。”
- 一上来解释背景、讲道理、报数据。

改稿方法：

- 把最有情绪的那句对话提前。
- 把最有画面的动作提前。
- 第一秒先让观众想知道“后来呢”。
- 开头不要超过两句才进入事件。

## 3. 表达够深入，30%

文案不能停在表面事实，要从小事里提炼出观众能感同身受的点。但深入不等于拔高，不等于说教。

必须做到：

- 有一个更深层的情感判断。
- 这个判断能从用户原话或素材里推出。
- 能让观众联想到自己家里的老人、孩子、家乡或过去经历。
- 不用宏大词，不做道德审判。

常见的深入方式：

- 从“买了吃的”到“孩子心里还给老人留着位置”。
- 从“奶奶自豪”到“老人被孩子记得，会高兴很久”。
- 从“奖学金和零花钱”到“孩子自己也不多，却先想到爷爷奶奶”。
- 从“爷爷奶奶走路接送”到“小时候被照顾过，长大后也可以回头惦记一次”。
- 从“家乡小事”到“很多亲情不说出口，但一看就懂”。

避免：

- 把故事上升成空泛社会议题。
- 指责年轻人“自我中心”。
- 强行输出“要感恩父母长辈”的教育口吻。
- 加入没有来源的苦情细节。
- 用“破防了”“泪目了”“太治愈了”替代真实表达。

改稿方法：

- 找出事件里最小但最有力量的动作。
- 用“不是……而是……”提炼。
- 用“小时候……长大后……”建立时间回声。
- 用“你有没有……”把观众带进来。

## 4. 结尾，10%

结尾要有互动，有钩子。不要只是总结观点。

好结尾标准：

- 有一句感动点总结。
- 有一个具体问题，观众可以马上回答。
- 问题能引导评论，而不是泛泛表态。
- 结尾回扣前面的真实细节。

可用句式：

```text
小时候他们一趟一趟走路接你，
长大后你有没有回头问过一句：
爷爷奶奶，你们最近想吃什么？
```

```text
不是多贵的东西，
是孩子心里还惦记着你。
你有没有给家里的老人买过一件他们舍不得买的东西？
```

```text
很多亲情不说出口，
但一袋吃的、一通电话，就够老人高兴很久。
你最近一次主动联系爷爷奶奶是什么时候？
```

避免：

- “欢迎点赞评论关注。”
- “你怎么看？”
- “这就是亲情的力量。”
- “让我们一起传承美德。”

## 快速自检

交付前按顺序问自己：

1. 前 3 秒能不能让人停下来？
2. 前因后果是否不用解释也听得懂？
3. 有没有从事实提炼出一个更深的共情点？
4. 有没有一句具体、能引发评论的问题？
5. 有没有编造用户没说过的情节？

如果第 1 条不成立，先改开头。如果第 3 条不成立，重写后半段。如果第 5 条不成立，删掉编造内容。
