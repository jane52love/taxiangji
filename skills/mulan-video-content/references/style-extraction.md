# 写作风格提取规则

当木兰提供文案样本、视频转写稿、过往发布内容或对标脚本时，先提取可复用的写作风格规则，再开始写新文案。目标是描述“这种文案怎么写出来”，不是夸它写得好。

不要使用下面这类空泛风格词：

- 高级
- 自然
- 有网感
- 真诚
- 接地气
- 温暖
- 治愈
- 松弛
- 像真人

如果这些词看起来确实相关，也要换成可观察的写法规则：句子长短、怎么开头、常用词、信息顺序、情绪克制方式、例子怎么进入、观点怎么落下来。

## 必须输出的风格格式

```markdown
## 可复用写作风格规则

### 开头方式
- ...

### 句子节奏
- ...

### 常用表达
- ...

### 转折习惯
- ...

### 观点结构
- ...

### 结尾引导
- ...

### 禁用写法
- ...
```

## 提取什么

### 开头方式

观察样本第一句话在做什么：

- 从看得见的物件开始：比如“这个坛子……”
- 从一个人开始：比如“隔壁婶婶今天……”
- 从问题开始：比如“你们见过这种菜吗？”
- 从对比开始：比如“城里人觉得普通，我们这儿……”
- 从记忆开始：比如“小时候一到这个季节……”
- 从判断开始：比如“这不是一道菜，是……”

提取时要写成规则，例如：“开头先给一个能看见的东西，不先讲大道理。”

### 句子节奏

观察并总结：

- 单句大概多长
- 是否常用短句或半句话
- 是否常用反问
- 逗号停顿多不多
- 每句话通常承载一个画面、一个动作，还是一个观点
- 是否反复使用某种句式

### 常用表达

提取可复用的表达类型，不只是摘抄原句：

- 人物关系词：婶婶、奶奶、邻居、种菜的人
- 感官和动作词：晒、腌、揉、翻、闻、尝、收、挑
- 谦逊的第一人称：我觉得、我后来才知道、我以前也没注意
- 地点和时间锚点：一到冬天、在我们这儿、村口、院子里、赶集那天

只有当某个原句明显是木兰常用表达，或用户要求保留原话时，才直接复用原句。

### 转折习惯

识别样本怎样转向：

- 用“但是”纠正前面的判断
- 用“后来我才知道”讲发现
- 用“其实”重新解释
- 用“不是……而是……”把意思翻一层
- 用“你看……”把话拉回画面

### 观点结构

描述样本怎样把意思讲出来：

- 先场景，再感受
- 先人物，再习俗
- 先物件，再历史
- 先事实，再木兰自己的看法
- 先问题，再通过日常生活回答

不要把每条短视频都写成三段式作文。口播结构要能说得出来。

### 结尾引导

观察结尾通常做什么：

- 请观众说说自己的记忆
- 回到开头的物件或人物
- 留一句轻轻的感慨
- 让有相似生活经历的人产生共鸣
- 引导了解、到访、购买或继续看下一条

### 禁用写法

每次都要写清楚具体不能怎么写。例如：

- 不用“在时代发展的浪潮中”这类宏大空话。
- 不连续堆四字词。
- 不把农村生活写成展览解说词。
- 不替当事人编内心独白。
- 不用“宝子们”“家人们”，除非木兰自己的样本里经常这样说。
- 不写未经确认的历史年份、收入数字、政策判断。
