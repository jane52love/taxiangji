# 视频样本解析规则

当用户提供多条视频素材时，先确认每条视频的角色，再解析。不要把所有视频混在一起学习。

## 视频角色划分

常见划分方式：

- 木兰自己的视频：用于提取木兰的说话风格、观察视角、句子节奏、常用表达和禁用写法
- 对标视频号：用于学习选题切口、开头钩子、内容结构、节奏安排、标题方法和评论引导
- 主题素材视频：用于观察画面、动作、人物、物件、场景和可用镜头
- 证据或知识视频：用于提取事实，但事实仍需和知识库或用户确认

如果用户说“视频 1 和 2 是木兰的，视频 3 和 4 是对标”，要严格按这个角色使用。

## 木兰视频怎么解析

木兰自己的视频不要只总结内容，要提取她“怎么说话”。按下面维度整理：

- 开头：她是先说今天去了哪里、先说看到什么、先问问题，还是先讲一个感受
- 句子：一句话大概多长，是否常用短句，是否有停顿和重复
- 视角：她更像参与者、带路的人、旁观记录者，还是向外地人解释的人
- 词语：她常用哪些地方词、称呼、动作词、时间词
- 转折：她怎么从画面转到故事、从故事转到观点
- 情绪：她是克制地讲、边做边讲、带一点笑意，还是更认真地说明
- 结尾：她会不会问观众、会不会回到画面、会不会留下下一条线索
- 不适合她的写法：哪些表达一听就不像她本人

输出格式：

```markdown
## 木兰说话风格提取

### 开头习惯
- ...

### 句子节奏
- ...

### 常用表达
- ...

### 画面到观点的转法
- ...

### 结尾方式
- ...

### 不要写成这样
- ...
```

## 对标视频怎么解析

对标视频不是用来模仿声音，而是学习“内容怎么组织”。按下面维度整理：

- 开头钩子：问题、反差、金句、画面冲击、人物悬念
- 信息顺序：先画面、先观点、先人物、先结果，还是先冲突
- 节奏：几秒一个信息点，是否有重复强调，是否留停顿
- 画面配合：口播和画面是解释关系、补充关系，还是反差关系
- 知识密度：一条视频讲几个事实，事实有没有被场景化
- 情绪推进：好奇、惊讶、怀念、骄傲、实用、反驳
- 标题方法：标题给观众什么承诺，是知识、故事、反差还是情绪
- 可借鉴方法：只写方法，不照抄原句

输出格式：

```markdown
## 对标视频内容方法提取

### 开头方法
- ...

### 内容结构
- ...

### 口播节奏
- ...

### 画面使用
- ...

### 标题方法
- ...

### 可以借鉴给木兰的地方
- ...

### 不能照搬的地方
- ...
```

## 合成规则

最终生成木兰文案时：

- 说话风格来自木兰视频
- 选题结构和节奏可以参考对标视频
- 事实和地方知识来自知识库
- 画面细节来自用户上传素材
- 观点和边界以木兰当前想法为准

不要让对标账号的腔调压过木兰。对标视频里再好的句子，也只能转成结构方法，再用木兰的说话方式重新写。

## 视频 1-4 样本工作流示例

如果素材说明是：

- 视频 1：木兰自己的视频，主题是茭白
- 视频 2：木兰自己的视频，其他主题或补充样本
- 视频 3：对标视频号
- 视频 4：对标视频号，主题是茭白

处理顺序：

1. 从视频 1 和视频 2 提取木兰说话风格。
2. 从视频 3 和视频 4 提取对标账号的口播结构、开头方法和标题方法。
3. 因为视频 1 和视频 4 都讲茭白，单独比较二者：
   - 木兰讲茭白时用了哪些真实画面和个人表达
   - 对标视频讲茭白时用了什么钩子、冲突或知识点
   - 哪些对标方法可以转成木兰口吻
   - 哪些表达不适合木兰，必须舍掉
4. 再结合茭白知识库，生成适合木兰的新脚本和口播。

## 无法直接解析视频时

如果当前环境没有视频抽帧、音频转写或播放能力，要向用户说明：

- 当前能读取到哪些文件
- 哪些内容还无法确认
- 需要用户补充什么：口播转写稿、关键帧截图、视频标题、评论反馈、账号链接

在没有转写或画面信息时，可以基于知识库和用户描述更新 skill 或生成模板，但不能声称已经提取了视频里的真实说话风格。
