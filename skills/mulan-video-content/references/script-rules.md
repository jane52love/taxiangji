# 脚本生成规则

这些规则用于生成木兰的短视频脚本、口播文案、标题和社媒文案。

## 先选一个叙事发动机

每条短视频优先选择一个主要叙事入口：

- 物件入口：老嫁妆、腌菜坛子、白菜、农具、手写纸条
- 人物入口：奶奶、邻居、种植户、手艺人、回乡的女儿、村里的女性
- 季节入口：收获、晒菜、冬储、过节准备
- 问题入口：“为什么我们这儿家家户户都要……”
- 对比入口：外地人的理解 vs 本地人的日常经验
- 过程入口：怎么做、怎么种、怎么腌、怎么晒、怎么修、怎么卖

一条短视频不要同时塞太多入口。如果素材里有好几个方向，优先选择画面最清楚、最能让观众马上看懂的那个。

## 口播结构

30-60 秒口播：

1. 一个看得见的开头
2. 一句背景
3. 两三个具体细节
4. 一个木兰自己的发现或感受
5. 一个能引导评论或记忆的结尾

90-180 秒口播：

1. 看得见的开头
2. 木兰为什么注意到它
3. 人物、物件或过程细节
4. 本地知识或背景
5. 木兰自己的看法
6. 结尾引导，或接到下一条视频

## Benchmark 优先级

生成和改稿时按这个权重判断优先级：

- 黄金 3 秒：40%。开头必须先抓住人，优先用真实对话、反差、动作或具体问题。
- 表达够深入：30%。不能只复述事实，要从小事里提炼出能让观众代入的情感点。
- 完整度：20%。前因后果要清楚，但不要为了交代背景把开头写钝。
- 结尾：10%。结尾要有具体互动问题，不能只喊点赞评论。

如果一版文案平铺直叙，先改前 3 秒；如果一版文案只是讲完事情，先改后半段的共情提炼；如果一版文案听不懂，再补必要背景。

## 口播可读性

- 文案要适合说出口，不是只适合默读。
- 多用短句；一句话如果一口气说不完，就拆开。
- 关键名词尽量放在句子前面。
- 先用具体动作，再讲抽象意义。
- 如果某句话像宣传稿，就改成从一个人、一个物件或一个场景里说出来。
- 一句话不要解释太多层意思。

## 用户原话处理

当用户要求“不要编，多挖掘我的内容”时，成稿要遵守这个边界：

- 不逐字照抄用户原话。原话通常有停顿、重复、临时改口，要整理成能直接口播的句子。
- 不脱离原话扩写新情节。没有被用户说出或素材证明的人物、动作、时间、地点，不要编进去。
- 保留真实对话中最有力量的句子，尤其是人物自己的话。
- 把重复表达压缩成一句更准的话。
- 用少量连接词让逻辑顺起来，例如“后来”“但是”“其实”“我觉得”“所以”。
- 在结尾提炼一层更能共情的意思，但这层意思必须能从用户原话里推出。

可用处理顺序：

1. 摘出事实：谁、做了什么、在哪里、因为什么。
2. 摘出原话：哪一句话最像现场真实发生的。
3. 摘出情绪：自豪、心疼、惦记、感恩、怀念、惊讶。
4. 摘出深层意思：这件小事为什么能打动更多人。
5. 重排成口播：真实场景开头，事实中段，提炼结尾。

## 提炼和升华

升华不是写大词，也不是喊口号。升华是从一个小动作里找到更多人能懂的意思。

优先使用这种提炼方式：

- 从“买了什么”提炼到“心里还惦记谁”
- 从“一个老人很高兴”提炼到“被孩子记得是一种幸福”
- 从“孩子懂事”提炼到“长大后还记得小时候谁带大自己”
- 从“一件家乡小事”提炼到“很多家庭都有这种不说出口的亲情”
- 从“我看见了”提炼到“你有没有也经历过”

避免：

- 把小事拔高成社会评论
- 直接批评“现在的孩子都以自我为中心”
- 用“感恩教育”“传统美德”“精神内核”这类讲台词
- 替人物编内心独白
- 为了感动而增加没有来源的苦情细节

## 结尾互动钩子

结尾要同时完成两件事：一句话总结感动点，带出一个观众愿意回答的问题。

好的结尾通常有这个结构：

```text
小时候/以前/那时候 + 一个具体付出，
长大后/现在 + 你有没有回头做过一个小动作？
```

也可以使用：

```text
不是多贵的东西，
是那句/那个意思：
我还想着你们。
```

互动问题要具体，不要只问“你怎么看”。优先问：

- 你有没有给爷爷奶奶买过他们舍不得买的东西？
- 你有没有问过爷爷奶奶最近想吃什么？
- 你小时候是谁一趟一趟接你回家的？
- 你家里有没有这样不说出口、但一看就懂的亲情？

## 满意稿样本规则

下面这类结构适合“身边故事 / 家乡亲情”：

1. 真实动作开头：邻居奶奶过来拿东西，手里提着吃的。
2. 用对话做钩子：“这是你儿子给你买的吗？”“不是哦，是我家孙女给我买的。”
3. 中段只交代必要事实：两个孙女，一个读大学，一个读初中；小时候爷爷奶奶带大；现在不在身边。
4. 情绪不直接喊感动，而是写“她特别自豪”“一直惦记爷爷奶奶”“怕他们舍不得吃舍不得喝”。
5. 结尾从老人和孩子两边一起落：“小时候他们一趟一趟走路接你，长大后你有没有回头问过一句：爷爷奶奶，你们最近想吃什么？”

这类满意稿的关键不是文采，而是：

- 开头有现场
- 中间有真实对话
- 事实够用就停
- 结尾从小事提炼出共情问题

## 知识库使用

使用知识库笔记时：

- 把事实转成和场景有关的口播句
- 专有名词、地方词要准确
- 不确定的信息标成“待确认”，不要假装确定
- 不编历史来源、产量、价格、荣誉、政策效果

示例：

- 知识库笔记：“本地白菜耐储存，冬季常用于腌制和晾晒。”
- 口播写法：“我们这儿一到冬天，院子里最常见的就是白菜。能放，也能腌，晒出来又是另一种味道。”

## 对标内容使用

对标视频号只能学习方法，不能照抄句子。重点提取：

- 它怎么开头
- 信息按什么顺序出来
- 标题给了观众什么期待
- 节奏快慢
- 它怎么从画面讲到观点

再把这些方法转成适合木兰素材和木兰口吻的写法。

## 标题

标题要写成一句话，不要使用分隔符，不要写成两段式标题。它可以是短标题，也可以是一句有画面、有情绪、有亮点的话。重点是让人愿意点进来，而不是硬卡字数。优先使用“地点、画面、动作、情绪、反差”中的 1-2 个元素，不要把信息塞满。

标题可以包含：

- 地点：村名、乡镇名、县名、山里、家乡、院子、田里、溪边
- 内容概括：傍晚、宾客寻凉、腌菜、晒秋、赶集、老人、孙女、茭白田
- 画面感：迷雾、热闹、傍晚、灯火、水声、山风、冬天

标题风格参考：

- 迷雾中的家乡
- 山里热闹起来了
- 石关乡的傍晚
- 一个院子晒着半个世纪的回忆
- 村里腌菜了
- 小溪边的洗菜声
- 奶奶收到孙女买的吃食
- 宾客进山寻凉
- 奶奶的骄傲
- 冬天进坛子了
- 山风吹到院里

常见角度：

- 物件好奇：奶奶的嫁妆
- 地方习俗：村里晒菜了
- 人物故事：奶奶的骄傲
- 知识解释：霜后才好吃
- 感受反思：她还惦记你

避免：

- 标题党、假悬念、过度煽情和道德评判
- 太长、太满、像新闻通稿
- “震惊”“绝了”“看哭了”“一定要看”这类强刺激词
- 只有抽象情绪，没有地点或内容，例如“这就是最好的亲情”
- 使用破折号、冒号、竖线、逗号等分隔符
- 为了短而短，导致没有画面和意思

## 反馈修改规则

当木兰对文案不满意，先给 3-5 个修改建议，再改稿。建议要具体，不能只说“可以更自然”“可以更有情绪”。

建议可以从这些方向里选：

- 黄金 3 秒：把最抓人的对话、动作、反差或问题提前。
- 表达深度：从表层事件再往下提炼一层共情点。
- 真实感：删掉像编出来的句子，保留木兰原话和现场细节。
- 口吻：改得更像木兰说话，少用书面词和宣传腔。
- 完整度：补清楚人物关系、起因或关键动作。
- 结尾：把泛泛总结改成具体互动问题。
- 标题：改成更简洁的地点/画面/内容概括。

示例：

```markdown
我建议可以从这 4 个方向改：

1. 开头更抓人：直接用“不是哦，是我家孙女买的”开场。
2. 情绪更深：把“买吃的”提炼成“孩子长大后还记得爷爷奶奶”。
3. 口吻更像木兰：删掉“感恩教育”这类词，换成“心里还惦记着他们”。
4. 结尾更互动：用“你有没有问过爷爷奶奶最近想吃什么？”收尾。
```

## 社媒文案

视频号/朋友圈：

- 2-5 个短段落
- 第一句先放场景或人物
- 结尾邀请观众分享自己的记忆、做法或地方经验

小红书：

- 可以有更清楚的信息标签
- 第一行仍然要具体，不要空喊价值
- 标签要围绕真实话题、地点、习俗、产品

宣传类内容：

- 先让地点、人物或产品被看见
- 通过用途和故事讲价值
- 除非用户明确要销售文案，否则不要写成广告腔
