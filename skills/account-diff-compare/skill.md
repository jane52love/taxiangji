# 短视频账号差异对比

输入两个短视频账号链接，逐层拆解后输出双账号差异对比 HTML 报告。不生成脚本，不出规则清单，只做差异对比。

## 输入格式

用户提供两个短视频链接：

```
https://v.douyin.com/xxx
https://v.douyin.com/yyy
```

支持抖音、快手等主流短视频平台。也可接受账号截图、视频文案文字、口述补充。

## 抓取流程

收到链接后，自动执行：

1. **WebFetch抓取**：逐个抓取链接内容
2. **提取信息**：从页面中提取账号名、视频文案、播放量、粉丝量等
3. **补全判断**：检查抓到了什么，缺什么
4. **缺失处理**：
   - 抓到文案但缺播放量 → 用文案内容分析，播放量标注"未知"
   - 抓到标题但缺文案 → 用标题作为文案分析
   - 全部抓到 → 直接进入分析
   - 全部抓不到 → 追问用户"请复制视频文案文字给我"
5. **进入分析**：无论抓到多少，都先按已有信息开始分析，不等用户补全

## 分析框架

核心原则：所有维度都围绕一个核心问题——**观众看到这条视频，心里经历了什么？** 不是分析"视频拍得好不好"，而是分析"观众的心理路径是什么"。

逐层拆解两个账号，每层做 A vs B 并排对比。

### 层1 账号画像

对比两个账号的基本信息和成长画像。

| 维度 | 账号A | 账号B |
|------|-------|-------|
| 账号名 | | |
| 平台 | | |
| 粉丝量 | | |
| 获赞量 | | |
| 作品数 | | |
| IP属地 | | |
| 账号简介 | | |
| 涨粉效率 | | |
| 爆款率 | | |
| 发布频率 | | |

核心判断：对比是"高质低产"还是"低质高产"，触达了"看一眼觉得好"还是"关注这个人"。

### 层2 内容分类

对比两个账号的内容类型分布。

**按主题分类**：把大类拆成子类型，统计每类占比和播放量。

| 大类 | 子类型 | 账号A占比 | 账号B占比 | A平均播放 | B平均播放 |
|------|--------|---------|---------|---------|---------|

**按形式分类**：

| 形式 | 特点 | 账号A | 账号B |
|------|------|-------|-------|
| 全程旁白型 | 全程配音串起过程 | | |
| 一句话型 | 一句文案+画面 | | |
| 纯画面型 | 无旁白只有音乐 | | |
| 对话型 | 和镜头里的人对话 | | |
| 口播型 | 对着镜头说话 | | |

**按时长分类**：

| 时长区间 | 账号A占比 | 账号B占比 |
|---------|---------|---------|
| <10秒 | | |
| 10-30秒 | | |
| 30-60秒 | | |
| >60秒 | | |

**按情绪分类**：

| 情绪 | 账号A占比 | 账号B占比 | A触发层 | B触发层 |
|------|---------|---------|--------|--------|
| 温暖 | | | 共鸣 | |
| 自豪 | | | 认同 | |
| 平静 | | | 共鸣 | |
| 感动 | | | 共鸣+好奇 | |

规律对比：哪个子类型数据最高？两个账号的内容组合差异在哪？

### 层3 文案风格对比

不逐条拆解，而是从两个账号各自的视频中提炼文案特征并对比。

**文案总公式对比**：

| 模块 | 账号A特征 | 账号B特征 |
|------|---------|---------|
| 画面描述 | | |
| 感受表达 | | |
| 点题收束 | | |

**关键维度对比**：

| 维度 | 账号A | 账号B |
|------|-------|-------|
| 平均字数 | | |
| 句式偏好 | | |
| 高频词 | | |
| 叙事视角 | | |
| 情感基调 | | |
| 收束公式 | | |

**用词对比**：各自的高频感受词、场景词、动作词。

**叙事视角对比**：

| 视角 | 账号A频率 | 账号B频率 |
|------|---------|---------|
| 我们（集体） | | |
| 第三人称 | | |
| 第一人称 | | |
| 无主语 | | |

### 层4 文案诗意度对比（朴实度校准）

对两个账号的文案，各自判断诗意度（0-5）：

| 档位 | 特征 | 账号A | 账号B |
|------|------|-------|-------|
| 0 | 纯大白话 | | |
| 1 | 口语+细节 | | |
| 2 | 口语+对比 | | |
| 2.5 | 口语+一点画面感 | | |
| 3 | 开始文学化 | | |
| 4 | 诗意化 | | |
| 5 | 散文诗 | | |

原则：以平实为主，可以偶尔带一点诗意，但不能过度。建议降到≤2.5。

### 层5 用户心理路径对比

对每条视频，拆解观众完整心理路径，做 A vs B 并排对比：

| 阶段 | 时间 | 观众心理 | 账号A | 账号B |
|------|------|---------|-------|-------|
| 触发期 | 0-0.5秒 | "这是什么？" | | |
| 判断期 | 0.5-3秒 | "要不要看？" | | |
| 投入期 | 3-10秒 | "他在做什么？" | | |
| 沉浸期 | 10秒-结尾 | "然后呢？" | | |
| 决策期 | 看完 | "要做什么？" | | |
| 留存期 | 看完之后 | "还想看下一条吗？" | | |

### 层6 心理触发层对比

对比两个账号各自在哪个触发层：

| 触发层 | 触发什么 | 用户反应 | 数据表现 | 账号A | 账号B |
|--------|---------|---------|---------|-------|-------|
| 零层 | 无触发 | 划走 | 低播放 | | |
| 一层 | 共鸣 | "我也是"→点赞 | 中播放 | | |
| 二层 | 共鸣+好奇 | "怎么做"→看完 | 高播放 | | |
| 三层 | 共鸣+好奇+互动 | "我要回答"→评论 | 超高播放 | | |

### 层7 流量逻辑对比

对比两个账号的流量触发和播放分布。

**三层流量池对比**：

| 层 | 触发情绪 | 人群 | 账号A | 账号B |
|----|---------|------|-------|-------|
| 共鸣层 | "我也想回家" | 离开家乡的人 | | |
| 好奇层 | "这个没见过" | 城市人 | | |
| 认同层 | "和我老家一样" | 农村人 | | |

一条视频触发越多层，数据越高。

**播放量分层对比**：各播放区间的占比。

**涨粉效率对比**：分析"为什么有人看但没人关注"或"为什么既有人看又有人关注"。关键维度：是否有人物（人设）、内容是否同质化、是否带平台标签、文案长度、情绪是否单一。

### 层8 人设逻辑对比

对比两个账号的人设构建。

**人设三要素对比**：

| 要素 | 账号A | 账号B |
|------|-------|-------|
| 身份 | | |
| 关系 | | |
| 态度 | | |

**人设边界对比**：各自"不做什么"（不卖惨、不炫耀、不教学、不评价、不煽情、不带货口播、不剧情演绎、不热点跟风）。

**信任链路对比**：

```
真实 → 观众觉得"不是演的"
↓
持续 → 观众觉得"一直这样"
↓
不评价 → 观众觉得"不试图影响我"
↓
信任 → 愿意关注和互动
```

关键判断：缺少"可识别的人"的账号，观众会点赞但不关注。固定人物出镜是建立人设的关键。

### 层9 标签策略对比

对比两个账号的标签使用。

| 层 | 作用 | 账号A频率 | 账号B频率 |
|----|------|---------|---------|
| 大流量池 | 进入平台大池（平台活动标签） | | |
| 中流量池 | 精准匹配人群（主题标签） | | |
| 小流量池 | 匹配搜索（内容标签） | | |

缺少平台活动标签 = 错过流量扶持。

### 层10 底层逻辑对照

七层底层逻辑，逐层做 A vs B 对照，标注用户心理：

| 层 | 逻辑 | 用户心理 | 账号A | 账号B |
|---|------|---------|-------|-------|
| 1 身份定位 | 观众关注"他是谁"不是"拍了什么" | "我想了解这个人" | | |
| 2 信任链路 | 关系链天然程度决定可信度 | "我信他说的" | | |
| 3 情绪深度 | "心疼"比"好看"深一层 | "我被触动了" | | |
| 4 内容护城河 | 不可复制性决定留存 | "只有他有这个内容" | | |
| 5 算法标签 | 有人设→精准推 | "这就是我想看的" | | |
| 6 用户心理路径 | 人让人想关注，风景让人划走 | "我想看他的下一条" | | |
| 7 信息聚焦 | 一个视频一件事 | "我知道我在看什么" | | |

## 输出格式

生成一个自包含 HTML 文件，包含以下模块：

### 1. HTML 结构

```
Hero区（标题+核心结论）
  ↓
01 两个账号概览（左右卡片，每个账号含视频样本）
  ↓
02 账号画像对比（层1：基本信息+成长画像并排表）
  ↓
03 内容分类对比（层2：主题/形式/时长/情绪分布对比）
  ↓
04 文案风格对比（层3：字数/句式/用词/视角/收束对比）
  ↓
05 文案诗意度对比（层4：朴实度校准，0-5评分并排）
  ↓
06 用户心理路径对比（层5：核心模块，6阶段心理路径图，A vs B并排）
  ↓
07 心理触发层对比（层6：零层→三层，两个账号各在哪层）
  ↓
08 流量逻辑对比（层7：流量池/播放分层/涨粉效率）
  ↓
09 人设逻辑对比（层8：身份/关系/态度/信任链路）
  ↓
10 标签策略对比（层9：三层标签）
  ↓
11 七层底层逻辑对照（层10：卡片网格，每层A vs B，标注用户心理）
  ↓
12 数据可视化对比（ECharts柱状图）
  ↓
13 差异总结（共同规律 vs 差异点 + 一句话总结 + 统计数据）
```

### 2. 配色方案（淡紫色清淡风）

```css
:root {
  --bg: #f6f4fb;        /* 淡薰衣草背景 */
  --bg2: #ffffff;       /* 卡片白底 */
  --bg3: #f0ecf7;       /* 次级背景 */
  --ink: #2e2a40;       /* 深紫灰正文 */
  --muted: #6b6580;     /* 灰紫次要文字 */
  --muted2: #9b95ad;    /* 更淡次要文字 */
  --rule: rgba(90,70,140,0.1);  /* 淡紫边框 */
  --accent: #7c5cbf;    /* 主色：紫 */
  --accent2: #d4615a;   /* 反面色：柔珊瑚红 */
  --accent3: #b8915e;   /* 副色：暖金 */
}
```

### 3. 图表要求

- 使用ECharts，renderer设为svg
- 颜色从CSS变量读取
- animation: false
- 包含tooltip
- 包含resize监听
- 图表1：各视频播放量对比柱状图
- 图表2：账号效率对比（粉丝量/作品数/平均播放三组数据）

### 4. 视觉层次

- Hero区：大标题44px + 副标题15px + 元数据行
- 章节标题：编号32px(serif) + 标题20px(bold) + 描述13px(muted)
- 账号卡片：边框用rgba区分A/B，内含视频样本列表
- 对比表：sticky表头，hover高亮，A列淡紫底色
- 逻辑卡片：编号badge + 标题 + 描述 + A vs B对照框
- 总结band：渐变背景 + 大字serif + 四组统计数据

### 5. 响应式

- 桌面：双列网格
- 手机（≤768px）：全部单列

## 使用流程

1. 收到用户提供的两个链接
2. WebFetch逐个抓取链接内容
3. 提取账号名、文案、播放量（能抓到多少抓多少）
4. 缺失信息按"缺失处理"规则执行
5. **先拆用户心理路径**：对每条视频，按6阶段（触发→判断→投入→沉浸→决策→留存）分析观众心理
6. **再判断心理触发层**：每个账号在哪层（零层→三层）
7. 按层1-层10逐层做 A vs B 并排对比
8. 判断文案诗意度（0-5）
9. 生成HTML文件（心理路径对比放在数据图表前面）
10. 复制ECharts到_shared/js/
11. 在assets/charts.js中写图表逻辑
12. 返回文件链接给用户
