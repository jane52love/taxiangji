# 对标账号分析

系统拆解短视频对标账号，从"看到什么"到"为什么"再到"怎么用"，分9层递进分析。

## 分析总览

```
A. 账号画像    → 他是谁
B. 内容分类    → 拍了什么
C. 文案规律    → 说了什么话（规则提炼型）
D. 脚本规律    → 怎么拍的
E. 流量逻辑    → 为什么有人看
F. 人设逻辑    → 为什么被信任
G. 标签策略    → 怎么被找到
H. 对标转化    → 怎么用
I. 跨账号对比   → 多个账号之间比什么
```

## 输入要求

用户需提供以下至少一项：
- 对标账号链接或抖音号
- 账号截图（主页/视频列表）
- 视频文案文字
- 口述补充的观察

信息越完整，分析越准确。信息不足时主动追问。

## A. 账号画像

### A1. 基本信息
账号名、平台、ID号、粉丝量、获赞量、作品数、IP属地、所在地、创作者身份、账号简介。

### A2. 成长画像
作品数与粉丝量比例、涨粉效率、爆款率（过万播放占比）、内容形态（纯视频/视频+图文）、发布频率。

**核心判断：** 判断是"高质低产"还是"低质高产"，判断内容触达了"看一眼觉得好"还是"关注这个人"。

### A3. 生产条件
拍摄设备、团队规模、后期工具、出镜情况。

### A4. 可对标性判断

| 维度 | 对标账号 | 目标账号 | 可对标度 |
|------|---------|---------|---------|
| 所在地 | | | ★★★★★ |
| 拍摄对象 | | | |
| 拍摄方式 | | | |
| 设备 | | | |
| 团队 | | | |
| 内容主题 | | | |
| 风格 | | | |

可对标度分5档：★完全一致 → ☆差异大。

## C. 文案规律（规则提炼型）

> 不逐条拆解，而是从所有视频中提炼出生成规则和公式，可直接写进提示词。

### C1. 文案生成总公式

```
文案 = [画面描述] + [感受表达] + [点题收束]
```

| 模块 | 作用 | 字数 | 规则 |
|------|------|------|------|
| 画面描述 | 让观众"看到" | 8-12字 | 用动词+名词，不用形容词 |
| 感受表达 | 让观众"感受到" | 5-10字 | 用具体感受词，不用抽象词 |
| 点题收束 | 让观众"记住" | 5-8字 | 用金句或对比句收 |

### C2. 画面描述规则

**规则1：用动词不用形容词**
- 错误："美丽的茭白田" → 正确："日晒雨淋风吹泥浸"

**规则2：用具体不用抽象**
- 错误："经历了很长时间" → 正确："历经二十多天"

**规则3：4种写法**

| 写法 | 公式 | 适用 |
|------|------|------|
| 过程式 | 动词1+动词2+动词3 | 加工类 |
| 环境式 | 地点+天气+时间 | 收获类 |
| 人物式 | 谁+在做什么 | 家人类 |
| 感官式 | 看到什么+闻到什么 | 季节类 |

### C3. 感受表达规则

**规则1：限定感受词类型**

| 类型 | 可用词 | 不可用词 |
|------|--------|---------|
| 温暖类 | 温暖、幸福、简单、平淡 | 温馨、浪漫、惬意 |
| 辛苦类 | 守着、汗水、历经 | 艰辛、劳苦、疲惫 |
| 自豪类 | 纯天然、独属、家的味道 | 高端、顶级、优质 |
| 仪式感 | 仪式感、馈赠、时节 | 仪式、纪念、庆典 |

**规则2：不超过10个字，超过就变成说教。**

### C4. 点题收束规则

**5种收束公式：**

| 公式 | 适用 | 示例 |
|------|------|------|
| "是___，更是___" | 强调归属 | "是岳西的味道，更是家的味道" |
| "___，也是___" | 递进补充 | "也是山里人简单的小欢喜" |
| "原来___就是___" | 感悟反转 | "原来粗茶淡饭就是最平淡的幸福" |
| "历经___，终于___" | 过程收束 | "历经二十多天，终于吃上" |
| 无点题，纯感受 | 留白型 | "简单，平淡，幸福" |

**收束必须"落回具体"：** 落到地名、情感关系或动作，不能悬空。不超过8字。

### C5. 句式变体规则

同一公式变着用，连续3条不能用同一种变体。至少准备7种变体轮换。

### C6. 用词规则

**白名单：** 感受词（简单/平淡/幸福/温暖）、场景词（必须具体地名）、时间词（必须具体数字）、动作词（挖/晾/守/换/种）、口语词（我们这里/家家户户）。

**黑名单：**

| 禁用词 | 替代方案 |
|--------|---------|
| 美丽/漂亮 | 用具体画面代替 |
| 值得一提 | 直接说 |
| 让我们一起 | 直接描述 |
| 总而言之 | 不需要总结 |
| 不仅而且 | 短句分开说 |
| 令人叹为观止 | 用感官描述 |
| 悠久历史 | 说具体年份 |
| 醇厚/绵长 | 用"好吃/好喝" |
| 质朴/淳朴 | 用"简单/实在" |
| 传承/匠心 | 用"一直这样做" |

### C7. 叙事视角规则

| 视角 | 使用频率 | 规则 |
|------|---------|------|
| 我们（集体） | 60% | 说地方特色时用 |
| 第三人称 | 25% | 拍别人做事时用 |
| 第一人称 | 10% | 偶尔表达个人感受 |
| 无主语 | 5% | 纯感受型，少用 |

不能混用。

### C8. 长度规则

| 内容类型 | 最佳字数 | 硬规则 |
|---------|---------|--------|
| 农产品制作 | 25字 | 必须有过程词 |
| 家人日常 | 20字 | 必须有人物 |
| 季节食物 | 22字 | 必须有时令词 |
| 一句话情感 | 8字 | 不需要结构 |

**硬规则：不超过30字。超过30字必须拆成两句。**

### C9. 文案-画面配合规则

| 配合类型 | 频率 | 规则 |
|---------|------|------|
| 升华型 | 80% | 画面拍过程，文案说感受 |
| 互补型 | 20% | 文案补充画面没有的信息 |

**硬规则：禁止文案和画面完全脱节。**

### C10. 标点节奏规则

- 句号收尾，不用省略号
- 5-10字一断
- 不用问号（不提问，直接说）
- 偶用感叹号（只在情绪强烈时）
- 逗号连接画面描述

**节奏核心：像日常说话——短、直接、不绕弯。**

## D. 脚本规律

### D1. 前3秒钩子

| 类型 | 怎么做 | 为什么有效 |
|------|--------|-----------|
| 动作钩子 | 一个正在进行的动作 | 好奇"在做什么" |
| 画面钩子 | 一个好看的画面 | 视觉停留 |
| 声音钩子 | 一个吸引注意的声音 | 听觉停留 |
| 悬念钩子 | 看到结果不知道过程 | 想看完整 |
| 情感钩子 | 一个让人共鸣的画面 | 情感共鸣 |
| 对比钩子 | 两个东西放一起 | 差异吸引 |

分析前3秒：说话还是不说话？近景还是远景？静还是动？有没有人出镜？

### D2. 视频结构

```
前3秒：钩子（不说话）
  ↓
3-15秒：展示过程
  ↓
15-25秒：细节特写
  ↓
25-30秒：收尾画面
```

### D3. 景别序列

| 序列模式 | 说明 |
|---------|------|
| 远→中→近→特→远 | 回环（最常用） |
| 特写→中→远 | 倒金字塔 |
| 中→近→特→中 | 回环 |
| 纯特写串接 | 细节流 |

### D4. 节奏

| 内容类型 | 总时长 | 镜头数 | 单镜头 |
|---------|--------|--------|--------|
| 农产品制作 | 30-60秒 | 5-8个 | 3-8秒 |
| 家人日常 | 15-30秒 | 3-5个 | 3-6秒 |
| 一句话情感 | 10-15秒 | 2-3个 | 5-8秒 |

### D5. 运镜

固定机位为主（70%），手持跟拍（20%），慢推（10%）。

### D6. 声音设计

| 元素 | 使用方式 |
|------|---------|
| 环境音 | 保留原声（掰断声、切菜声等） |
| 背景音乐 | 安静纯音乐 |
| 旁白 | 配音朗读文案 |

### D7. 收束

| 类型 | 效果 |
|------|------|
| 成品收 | 满足感 |
| 远景收 | 余韵 |
| 人物收 | 情感 |
| 行为收 | 日常感 |

## E. 流量逻辑

### E1. 三层流量池

| 层 | 触发情绪 | 人群 |
|----|---------|------|
| 共鸣层 | "我也想回家" | 离开家乡的人 |
| 好奇层 | "这个没见过" | 城市人 |
| 认同层 | "和我老家一样" | 农村人 |

**一条视频触发越多层，数据越高。**

### E2. 播放量分层

统计各播放区间的占比和特征。

### E3. 涨粉效率分析

分析"为什么有人看但没人关注"或"为什么既有人看又有人关注"。

关键维度：是否有人物（人设）、内容是否同质化、是否带平台标签、文案长度、情绪是否单一。

---

## F. 人设逻辑

### F1. 人设三要素

| 要素 | 怎么构建 | 效果 |
|------|---------|------|
| 身份 | 本地人/职业/年龄 | 观众知道他是谁 |
| 关系 | 拍谁/和谁互动 | 观众觉得真实 |
| 态度 | 不做什么 | 观众信任他 |

### F2. 人设边界

不卖惨、不炫耀、不教学、不评价、不煽情、不带货口播、不剧情演绎、不热点跟风。

**"不做什么"比"做什么"重要。**

### F3. 信任建立

```
真实 → 观众觉得"不是演的"
↓
持续 → 观众觉得"一直这样"
↓
不评价 → 观众觉得"不试图影响我"
↓
信任 → 愿意关注和互动
```

### F4. 关键判断

**缺少"可识别的人"的账号，观众会点赞但不关注。** 固定人物出镜是建立人设的关键。

## 分析输出清单

每分析一个账号，产出：
1. 账号画像表（A层）
2. 内容分类统计表（B层，含逐条视频明细）
3. 文案生成规则（C层，规则提炼型，可直接写进提示词）
4. 脚本规律表（D层）
5. 流量规律总结（E层）
6. 人设分析（F层）
7. 标签策略表（G层）
8. 对标转化清单（H层）
9. 跨账号对比表（I层，多账号时）

## 使用流程

1. 用户提供对标账号（链接/抖音号/截图/文案）
2. 按A→I逐层拆解
3. C层用规则提炼型，不逐条拆解，而是提炼生成公式
4. 每拆完一个账号，更新跨账号对比表
5. 最终提取通用规律 + 适合目标账号的个性化规律
6. 将规则写进提示词和知识库
