# 我的素材

每次对话确认主题后，产出的标题、文案、图片统一归档在这里。

## 文件夹命名规范

```
YYYY-MM-DD-标题
```

- 日期：归档当天
- 标题：木兰确认的最终标题（或主题简称），去掉 `/ \ : * ? " < > |` 等不适合做文件名的字符
- 示例：`2026-08-30-一个院子晒着半个世纪的回忆`

## 文件夹内容

```
我的素材/
└── 2026-08-30-一个院子晒着半个世纪的回忆/
    ├── 文案.md        # 主体文案（必含）
    ├── 1.jpg          # 本次上传的图片（按上传顺序编号）
    ├── 2.png
    └── 3.jpeg
```

### 文案.md 结构

```markdown
# 标题

## 视频形式
- 发布平台：微信视频号
- 视频时长：60 秒

## 视频脚本
（按时间段或镜头段落：画面 + 口播对应 + 情绪转折）

## 口播文案
（能直接读出来的 60-90 秒口播稿）

## 标题推荐
（至少 5 个备选标题；最终采用的一个放最前）

## 视频号配文
（2-5 个短段落，结尾邀请互动）

## 备注
（需要核实的事实、下次可改进的点）
```

### 图片命名

按上传顺序编号：`1.jpg`、`2.png`…（保留原始扩展名）。

## 归档方式

- 当前版本：由智能体在对话中确认后写入本文件夹，并向木兰展示保存路径
- 前端上线后：对话页点「归档」按钮，前端调用保存（见 docs/frontend-spec.md）

## 使用建议

- 开新主题对话前，可以让智能体参考已有素材文件夹，保持口吻和选题延续性
- 已发布后，可在 `文案.md` 的「备注」里补记实际数据（播放、点赞、评论），沉淀为下次选题依据
