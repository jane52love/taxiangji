# 我的知识

智能体在生成文案时引用的知识库，全部为 Markdown，可直接手动编辑维护。

## 目录

```
我的知识/
├── README.md                    # 本文件
├── 金梅姐说话风格规则.md          # 木兰的说话风格生成规则（句式、用词白/黑名单）
└── 场景触发库/                   # 22 个主题，每个主题一个文件
    ├── 00-主题索引.md            # 触发词总索引（新增主题后在这里补一行）
    ├── 01-茭白.md
    ├── 02-茶叶.md
    └── ...（共 22 个主题）
```

## 如何维护

### 修改某个主题

直接编辑 `场景触发库/NN-主题名.md`。每个主题的统一结构：

```
触发词 → 她可能怎么说 → 情绪基调 → 感官素材 → 口语化信息 → 对比冲突 → 可延伸角度（含脚本结构）→ 金句 → 关联触发
```

- **触发词**：木兰输入中出现这些词时，智能体命中该主题（如「茭白」「腌菜」「孙女」）
- **口语化信息**：木兰能说出口的真实事实，是文案素材的主要来源
- **可延伸角度**：每个角度就是一个可拍的脚本方向

### 新增主题

1. 复制任一主题文件，按统一结构填写，保存为 `NN-主题名.md`（NN 顺延编号）
2. 打开 `场景触发库/00-主题索引.md`，在表格末尾补一行（编号、主题、触发词、文件链接）

### 调整说话风格

编辑 `金梅姐说话风格规则.md`。核心原则：**朴实 > 诗意**，像跟邻居聊天，不像写散文。句式公式（S1-S5）、变体（V1-V7）、用词白名单/黑名单都在这个文件里。
