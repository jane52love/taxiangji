## 3. 茯苓与中药材

**触发词：** 茯苓 / 挖茯苓 / 中药材 / 葛根 / 天麻 / 上山挖 / 收药材

**她可能怎么说：**
- "今天上山挖茯苓了"
- "拍了茯苓加工"
- "很多人不知道我们这里产茯苓"
- "在收药材"

**情绪基调：** 有点惋惜的好东西，像在说一个被忽略的宝藏

**感官素材：**
- 视觉：山上的松树林、泥土里挖出的茯苓、切开后的白肉、切片时的纹路、竹匾上晒着的白色片
- 听觉：锄头挖土的闷响、刀切茯苓的沙沙声、竹匾翻动的声音
- 嗅觉：泥土的湿气、松木的清香、茯苓淡淡的药香、晒干后的干香
- 触觉：刚挖出来的湿凉、切面的粉质感、干片的轻脆

**口语化信息：**
- "很多人不知道我们这里产茯苓，其实是比较大的种植基地"
- "需要松树才可以种"
- "挖出来直接卖到街上收购点，或者等人来收"
- "没有规模化加工，因为要机器削皮切片烘干"
- "茯苓泡茶喝，祛湿"
- "当地人没宣传这个点"
- "好东西就在身边但没人知道"

**对比冲突：**
- 别处：产业化、有品牌、人人知道
- 我们：散户种、没品牌、没人知道
- 实际：产量大、品质好
- 认知：知道的人很少

**可延伸角度：**

### 角度1：科普揭秘型——"你们可能不知道我们这里产茯苓"
- 钩子：拿着一块刚挖的茯苓，说"你们知道这是什么吗"
- 展开：拍上山挖的过程，讲需要松树才能种，讲当地的种植规模
- 收束：切片晒干，说"这个可能就在你喝的茶里"

### 角度2：过程展示型——"从山上挖到切片烘干"
- 钩子：拍锄头挖进土里，"今天上山挖茯苓"
- 展开：挖→削皮→切片→烘干→晒，全过程手部动作
- 收束：竹匾上摆满白色茯苓片，"从泥里到你杯里"

### 角度3：遗憾型——"好东西就在身边但没人知道"
- 钩子："我们这里产茯苓，但很多当地人都不太清楚"
- 展开：拍收购点、拍散户送药材、讲没有品牌没有宣传
- 收束："要是有人帮我们说一下就好了"

**金句：**
- "很多人不知道我们这里产茯苓"
- "需要松树才能种出来"
- "好东西就在身边，但没人知道"

**关联触发：** 象形村 → 张家村 → 高山蔬菜 → 特产
