# 她乡记 · PRD

> 版本 v0.2 · 2026-08-30 · 依据《数字木兰-10组-她乡记-产品整合文档》（2026-08-29）整理

## 1. 产品概述

**一句话介绍：** 让普通的「她」，把正在经历的生活和画面快速形成文案，变成能拍、能说、能传播的家乡故事。

**定位：** 面向真实乡村内容创作者（木兰）的视频内容挖掘与脚本生成工具。

**核心理念：** 不是让 AI 替家乡说话，而是帮助真正生活在那里的人，把自己原本想说的话说出来。把「我脑子里有很多东西，但不知道怎么说」变成「我知道这条视频该怎么拍、怎么讲、怎么发」。

## 2. 背景与需求

木兰为家乡（岳西县石关乡）拍宣传视频的困难：不是没有内容，而是脑子里有很多真实经历、地方知识和生活故事，短时间内难以整理成一条清楚、有吸引力、有传播力的视频。

- 家乡的风景、生活和人物都在脑子里，但不知道从哪里讲起
- 网上常见宣传文案不像她自己，容易写成空泛介绍
- 希望用返乡女性的眼睛和声音讲这里的生活，讲出个人感受和真实故事

**MVP 方向：** 用 AI 改造现有内容生产流程——输入已有视频、知识库、想法和对标视频号，以主动提问、知识库调用、想法梳理为核心，输出视频脚本和口播文案。不追求全自动视频制作，先让木兰真正用起来。

## 5. 核心工作流（场景 1）

```
初始想法输入 → 素材识别 → 场景触发（知识库）→ 多轮信息挖掘
→ 知识库调用 → 对标方法参考 → 木兰风格约束
→ 视频脚本生成 → 口播文案生成 → 标题与视频号配文生成
→ benchmark 自检和改稿 → 木兰确认 → 归档到 我的素材/
```

### 5.1 多轮挖掘规则

- 木兰明确要求「不要编，先挖掘我的内容」时，一轮只问一个问题，追问 3-4 轮
- 挖掘方向：最打动你的画面/对话 → 那一刻最强的感觉 → 背后的真实关系/经历 → 想让观众记住哪一句
- 不边问边大量生成

### 5.2 修改规则

木兰不满意时不整篇重写，先给 3-5 个具体修改建议（开头更抓人 / 情绪更深 / 口吻更像木兰 / 结尾更互动 / 标题更精炼），木兰选定方向后再改。

## 6. 输出标准：四件套

| 项 | 要求 |
|----|------|
| 视频形式 | 置顶：发布平台 + 视频时长 |
| 视频脚本 | 按时间段/镜头段落：画面拍什么、哪句口播对应哪段画面、情绪转折 |
| 口播文案 | 能直接读出来，60-90 秒，句子短，不写宣传腔，不编没说过的情节，对原话筛选/重排/提炼/连接 |
| 标题推荐 | 一句话、不用分隔符、不两段式；用地点/画面/动作/情绪/反差 1-2 个元素；至少 5 个备选 |
| 视频号配文 | 2-5 个短段落，第一句放场景或人物，结尾邀请观众分享，不写硬广告 |

## 7. 成稿评测（benchmark）

| 维度 | 权重 |
|------|------|
| 黄金 3 秒（真实对话/反差/动作/具体问题开场） | 40% |
| 表达够深入（共情、思考、打动人） | 30% |
| 完整度（前因后果讲清楚） | 20% |
| 结尾（互动、钩子） | 10% |

交付前按此自检改稿，优先级同权重排序。

## 8. 数据沉淀

### 8.1 我的素材（详见 [我的素材/README.md](../我的素材/README.md)）

每次对话确认主题后归档：`我的素材/YYYY-MM-DD-标题/`，内含 `文案.md`（四件套）+ 本次上传图片（按顺序编号）。

### 8.2 我的知识（详见 [我的知识/README.md](../我的知识/README.md)）

- `场景触发库/`：22 个主题文件 + 触发词索引（已从原始大文件解析，可手动维护）
- `金梅姐说话风格规则.md`：句式公式、用词白/黑名单，核心原则「朴实 > 诗意」

知识库优先级：规则约束 > 金梅姐说话风格 / 对标账号分析 > 场景触发库 > 地方背景事实。

## 9. 技术方案

- **前端：** PWA（manifest + service worker），安卓 Chrome 为主要目标，可添加到主屏幕
- **智能体：** TRAE 主智能体，前端按场景注入 Skill 上下文（对接协议待定，见 [frontend-spec.md](frontend-spec.md) 预留配置）
- **语音输入：** 默认语音，Web Speech API（安卓 Chrome 支持），不可用时降级为文字输入
- **实现分工：** 前端代码由 codex 编写，规格见 [frontend-spec.md](frontend-spec.md)，产物放 `frontend/`

## 10. 使用边界

**解决：** 从一个模糊想法或一段素材，生成一份可以开始拍摄和发布的视频内容方案。

**不解决：** 自动完成完整视频剪辑、自动发布到平台、无素材时自动编故事、专业影视级分镜。
