# 她乡记 · 前端规格说明（交给 codex）

> 本文档是前端实现的完整需求。实现代码放入项目根目录 `frontend/`。
> 背景与业务规则见 [PRD.md](PRD.md)，本文只讲前端做什么。

## 1. 目标

为「她乡记」构建一个移动端 PWA：安卓手机优先，添加到主屏幕后像原生 App 一样全屏使用。前端是 TRAE 主智能体的对话壳——主页面 4 个场景入口，进入后与智能体对话完成内容创作，最终把确认的标题、文案、图片归档。

**用户：** 木兰（单人，非技术用户）。所有交互必须简单、大字号、大按钮。

## 2. 技术要求

- PWA：`manifest.json` + Service Worker，支持添加到主屏幕、全屏（standalone）、基础离线壳（静态资源缓存）
- 目标环境：安卓 Chrome（Web Speech API 可用）；桌面浏览器可正常降级使用
- 技术栈不限（建议 Vite + 原生 JS 或 Vue/React 任一轻量方案），保持简单可维护
- 中文界面

## 3. 页面结构

### 3.1 主页面（/）

- 顶部：产品名「她乡记」+ 一句 slogan（如：把正在经历的生活，变成能拍能说的家乡故事）
- 中部：4 个场景入口卡片，纵向排列，大图标 + 名称 + 一句话说明：

| # | 名称 | skill 标识 | 说明文案 | 状态标识 |
|---|------|-----------|---------|---------|
| 1 | 她乡记文案 | `mulan-video-content` | 从你的见闻和图片，挖掘出能拍能讲的视频文案 | 可用 |
| 2 | 对标账号文案 | `benchmark-copywriting` | 拆解对标账号的文案规律，写出你的风格 | 可用 |
| 3 | 对标账号分析 | `account-diff-compare` | 两个账号逐层对比，生成差异报告 | 可用 |
| 4 | 视频号首页素材生成 | `video-homepage-material` | 即将上线 | 待更新（置灰、不可点击） |

- 底部（或顶部入口）：「我的素材」「我的知识」两个次级入口（可先做成简单列表页，见 3.4）

### 3.2 对话页（/chat/:skillId）

所有场景共用一个对话壳，按 skillId 注入不同的场景上下文。

**消息流区域**
- 气泡式对话，智能体消息左对齐，用户消息右对齐
- 支持渲染 Markdown（文案产出是 md 格式，标题/列表/表格较多）
- 图片消息显示缩略图，点击可放大
- 长文案（如四件套）渲染为卡片式内容块，带「复制」按钮（一键复制纯文本）

**输入区域（固定底部）**
- **默认语音输入**：大麦克风按钮，按住说话（或点击开始/结束），实时转文字到输入框，可编辑后再发送
  - 使用 Web Speech API（`webkitSpeechRecognition`），语言 `zh-CN`
  - 不可用（如非 HTTPS、桌面无权限）时自动隐藏语音按钮，仅保留文字输入
- **文字输入**：点击输入框切换为键盘输入，发送按钮
- **图片上传**：相册/相机入口（`<input type="file" accept="image/*" multiple capture 可选>`），上传后显示缩略图预览列表，可删除，随消息一起发送
- 输入区高度自适应，弹起键盘不遮挡

**场景引导**
- 进入对话页时，智能体发出场景开场白（按 skill 预置，如场景 1：「说说你今天看到了什么？也可以直接传图片或视频截图」）

**归档交互（场景 1/2 核心闭环）**
- 当智能体产出四件套且木兰确认后，出现「归档」操作：前端收集最终标题、文案全文、本次会话上传的图片，保存为一个素材文件夹
- 归档确认弹窗展示：文件夹名（`YYYY-MM-DD-标题`，可编辑）、将包含的图片清单
- 归档实现方式见第 5 节（智能体对接待定，两条路径都要预留）

### 3.3 报告查看（场景 3 产物）

`account-diff-compare` 产出 HTML 差异对比报告。对话流内嵌一个「打开报告」按钮，点击后以 iframe / 新窗口渲染报告 HTML。

### 3.4 素材库页（/materials，可后置）

- 列表展示 `我的素材/` 下的文件夹（名称 = 日期-标题），点开查看 `文案.md`（渲染 Markdown）和图片
- 只读浏览即可，不做编辑

### 3.5 知识库页（/knowledge，可后置）

- 只读浏览：主题索引 + 各主题文件（渲染 Markdown）
- 不做在线编辑（手动维护在电脑端进行）

## 4. PWA 具体要求

- `manifest.json`：name「她乡记」、short_name「她乡记」、`display: standalone`、主题色与图标（提供 192/512 png，图标可用简洁文字图标）
- Service Worker：预缓存应用壳（index.html、css、js）；API 请求不做离线缓存（直接透传，失败提示网络错误）
- iOS Safari 兼容为次级目标（meta 标签 apple-touch-icon 等），不要求完美

## 5. 智能体对接（接口层预留）

当前对接协议待定。**请把对接封装成独立的 `src/api/agent.js`（或等价模块），UI 不直接依赖具体协议**，暴露统一接口：

```js
// 伪代码示意，签名可调整
sendMessage({ skillId, messages, images, signal }) -> stream / response
```

预留两种实现路径（可用环境变量/配置切换）：

1. **HTTP API 模式**：POST 对话消息（含图片），支持流式返回（SSE 或 fetch stream），逐字渲染
2. **占位模式（先用起来）**：在无后端时，提供本地 mock 响应，保证 UI 可开发调试

每次请求需携带：`skillId`（场景标识）、完整对话历史、图片（base64 或 FormData）。系统提示词/Skill 上下文由服务端注入，前端只传 skillId。

**配置项**（集中放一个 config 文件，字段先占位）：

```js
export const AGENT_CONFIG = {
  mode: 'mock',        // 'mock' | 'http'
  baseUrl: '',         // 待定：智能体服务地址
  apiKey: '',          // 待定
  stream: true,
}
```

## 6. 数据与状态

- 对话历史：按 skillId 分别保存（localStorage 起步即可，字段：messages[]，含 role/content/images/时间戳），支持清空当前场景对话
- 待归档会话：记录本会话上传的图片与最终确认的标题/文案，供归档使用
- 无需用户登录（单用户）

## 7. 非功能要求

- 移动端优先的响应式，基准视口 360-430px 宽，最大宽度限制（桌面居中展示）
- 字号偏大（正文 ≥16px），按钮触控区 ≥44px
- 对话消息发送中/生成中有明确的加载状态（打字指示器）
- 网络错误有友好提示与重试
- 所有静态文案中文

## 8. 交付物

- `frontend/` 完整可构建项目（含 README：如何 `npm install && npm run dev / build`）
- `dist/` 构建产物可直接部署到任意静态托管
- PWA 图标 192/512
- 一份简要的「已实现/未实现/待定」清单（对照本文档第 3、5 节）

## 9. 待定事项（前端先预留，不要硬编码）
